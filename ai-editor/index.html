ルート2｜子ども実行委員として一緒につくりたい

子どもも一緒につくるイベントへ

小学生から高校生を中心とする子ども・若者が、自分で考え、選び、できる範囲で挑戦する参加方法です。大人は、安全や大切な判断を支えます。

全部やらなくて大丈夫。できることを、できる範囲で。

役割の例

  • 企画ミーティング
  • 猫企画
  • ポスター・イラスト
  • SNS
  • 会場装飾
  • 受付・案内の補助
  • 写真・動画
  • 取材
  • アンケート
  • 準備・片付け
  • 振り返り

子どもに安全管理、金銭管理、契約、介助、緊急対応、個人情報管理の最終責任を任せることはありません。

子ども実行委員の情報を受け取りたい

ルート3｜場を支えたい

人が気持ちよく過ごせる場を、一緒につくる

人前に立つことだけが、役割ではありません。気づくこと、整えること、誰かにつなぐことも、大切な参加です。

できることを、できる範囲で。

詳しい参加方法や時間帯は、募集内容が決まり次第お知らせします。

  1. 場を支える役割例を見る
  2. 自分にできそうなことを考える
  3. 募集開始後、関心登録または申込みをする
  4. 事務局から説明や役割案内を受ける
  5. 必要に応じて事前説明や打合せに参加する
  6. 当日、案内された役割を担当する
  7. 終了後、振り返りや片付けに協力する

役割例

  • 会場準備
  • 受付
  • 出展者案内
  • 来場者案内
  • 清掃・片付け
  • 机・椅子・通路を整える
  • 写真・動画記録
  • SNS発信
  • 休憩場所への案内
  • 困っている人を担当者につなぐ

運営の経験が、地域の備えにもつながる

受付、案内、休憩場所づくり、清掃、役割分担、公民館の動線を知ること。文芸フリマを丁寧に運営する経験は、結果として、いざという時にも支え合える地域づくりにつながります。

希望する方への活動記録・活動証明の仕組みも検討しています。

場を支える参加情報を受け取りたい

ルート4｜遊びに行きたい・読みに行きたい

作品と人に会いに行く

作品を見る、作者と話す、ワークショップを楽しむ。猫をテーマにした展示や、子どもたち・地域の人の作品と活動にも出会える場を検討しています。

猫から広がる、小さな学び

「猫が好き」を入口に、ペット用の水・フード・トイレ用品、避難時に必要な情報、ペットとの避難、飼い主同士の助け合いなどを調べて伝える展示やワークショップを検討しています。

好き → 調べる → つくる → 伝える → 誰かの役に立つ

正式な日時・来場条件は、決まり次第お知らせします。
